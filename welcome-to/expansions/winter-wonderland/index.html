📦 What's New
  • 50 snowy score sheets — winter-themed neighbourhood with frozen pools, snowmen, candy canes, and light-blue artwork by Anne Heidsieck
  • 3 festive city plan cards — Christmas-themed objectives that replace one of the base game's city plans
  • Street light scoring — a new end-game scoring area on the sheet where you earn points for the longest consecutive run of houses on each street
💡 This is one of the lightest Welcome To… expansions — it adds a single new scoring dimension without changing core turn structure.
🔀 Rule Changes

Street Lights (Christmas Lights)

The core mechanic is unchanged — you still flip cards and write house numbers in ascending order. The new twist happens at the end of the game:

  1. On each of the 3 streets, find the longest unbroken run of consecutively numbered houses (e.g. 3, 4, 5, 6 = run of 4).
  2. Draw a string of Christmas lights connecting those consecutive houses.
  3. Score points equal to the length of the longest run on that street.
💡 Bis counts! A Bis duplicate (e.g. 5a, 5b) counts as consecutive for light-string purposes. This makes Bis far more valuable than in the base game — the minus points from Bis can be offset by a longer light string.

Festive City Plan Cards

The expansion includes 3 new city plan cards. You pick 1 to use as the no. 3 contract (replacing the base game's third city plan). The other 2 go back in the box.

The festive plans focus on:

  • Consecutive estates — complete an estate where all houses are in consecutive numerical order (rewarding the lights strategy)
  • Large consecutive runs — build a full 6-house estate with consecutively numbered houses
  • Non-consecutive small estates — complete small estates that are specifically not consecutive (the "Scrooge" houses that don't get lights)
⚠️ You can also mix: use 1–2 festive plans alongside base game city plans. But using all 3 festive plans gives the most thematic experience.
⚙️ Setup Changes
  1. Give each player a Winter Wonderland score sheet instead of the base game sheet.
  2. Shuffle the 3 festive city plan cards. Pick 1 to use as city plan no. 3. Return the other 2 to the box.
  3. Use city plan cards no. 1 and no. 2 from the base game (or swap in other expansion plans if desired).
  4. Set up the construction card decks exactly as in the base game — no changes to the card decks.
💡 Everything else is identical to base game setup. The construction cards, turn structure, and all 6 action types remain the same.
🏆 Scoring Changes

End-game scoring adds the Christmas Lights row. For each street, score points equal to your longest consecutive run:

Street 1 (top)1010 pts
Street 2 (middle)1111 pts
Street 3 (bottom)1212 pts
Theoretical maximum33 pts

All other scoring categories remain the same as the base game (estates, parks, pools, temps, city plans, Bis penalties).

💡 Realistically, getting 6–8 points per street is a strong result. A perfect consecutive street is extremely rare.
⚠️ Gotchas / Common Mistakes
  • Lights are scored at game end only — don't draw the light strings during the game. Wait until all turns are done, then find the longest consecutive run on each street.
  • Ascending ≠ consecutive — houses 3, 5, 7 are in ascending order but NOT consecutive. Only 3, 4, 5 counts for lights.
  • Bis helps, not hurts — 5a and 5b count as consecutive. Don't avoid Bis like you might in the base game; it's a key tool here.
  • Gaps kill runs — a single missing number breaks the chain. Plan spacing carefully early on so you can fill gaps later.
  • Only the longest run counts — if a street has runs of 4 and 3, you score 4 (not 7).
  • Festive plan selection — you pick 1 of 3 festive plans, not all 3. The other 2 go back in the box.
  • Light-blue sheets + blue pen — the snowy sheet has a blue tint. Use a dark pen or marker; fading blue ink is hard to read.
