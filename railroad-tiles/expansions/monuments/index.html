🔀 Rule Changes

The Archaeologist

Each player gets an archaeologist meeple that moves across their personal tile landscape. Movement uses the road and rail connections you've built:

  • Road movement (Highway) — spend 1 action point to move the archaeologist to an adjacent tile connected by road. Slow but flexible.
  • Rail movement (Railway via Stations) — spend 1 action point to move the archaeologist from one Station to any other Station connected by an unbroken railway. Much faster — can jump across your entire network in one action.
💡 Rail travel is the key advantage — a connected rail network lets your archaeologist zip across the map in a single action point, while roads require tile-by-tile movement.

Action Points

Each round you receive 3 action points to spend on your archaeologist. Actions:

  1. Move (1 AP) — move via road (1 tile) or rail (station-to-station)
  2. Dig (1 AP) — when the archaeologist is on a tile with an empty monument pinpoint, place a monument pawn of the indicated type (Arch, Temple, or Tower)

Unspent action points are lost — they do not carry over between rounds.

Trading Meeple Placement for Actions

On your turn, you may forgo placing a meeple from the active zone (train, car, or passenger) to gain +1 action point that round, giving you 4 AP total.

⚠️ This is a real trade-off — meeple placement scores immediate network points, while the extra action point is an investment in future monument set collection scoring.
⚙️ Setup Changes
  1. Add the Monuments tile bag alongside the base game bag. When refreshing the display, replace 1–2 base game tiles per column with tiles drawn from the Monuments bag (per the setup pattern on the expansion flyer).
  2. Give each player an archaeologist meeple — it starts off the board and is placed on the player's first tile that contains a monument pinpoint (or any tile of their choice at the start of the game).
  3. Place the monument pawns (Arches, Temples, Towers) in a shared supply within reach of all players.
  4. If using expansion objectives, shuffle the Monuments goal tiles and deal 3 to each player (same as base game goals).
  5. Replace the appropriate circular discs with the Monuments expansion discs as indicated in the rules.
💡 Only one expansion can be used per game. Do not mix Monuments tiles/discs with another expansion.
🏆 Scoring Changes

Monument Set Collection

Monuments do not score when placed. At game end:

Scoring CategoryPoints
Each monument pawn on your tiles1 pt each
Each complete set of 3 different monuments (Arch + Temple + Tower)+3 pts bonus

So a complete set of 3 is worth 6 points total (3 individual + 3 bonus). Two complete sets = 12 points, etc.

Expansion Objectives

  • Museum — archaeologist must be on or adjacent to the Museum tile at game end (5 VP)
  • Castle — must have at least 2 Tower monuments adjacent to the Castle tile (5 VP)
  • Other objectives follow similar positional/collection requirements

All Other Scoring Unchanged

Rectangle bonus, city scoring, meeple network scoring, and open-end penalties all remain as in the base game.

💡 Monument scoring competes directly with meeple placement scoring — every time you trade a meeple for an extra action point, you're sacrificing guaranteed network points for potential set collection points.
⚠️ Gotchas / Common Mistakes
  • Monuments don't score when placed — only at game end. Don't add points mid-game when you dig.
  • Rail movement requires Stations — you can only jump via rail if both the origin and destination tiles have Station symbols and are connected by an unbroken railway. No station = no rail travel from that tile.
  • Action points don't carry over — use them or lose them each round. Plan your archaeologist's route ahead.
  • Trading meeple placement is optional — you don't have to sacrifice a meeple for the extra AP. Evaluate whether the 4th action point is actually worth more than the network points you'd score.
  • Archaeologist placement timing — the archaeologist starts off-board. Make sure you know when it enters play (first monument tile placed or start of game, per your chosen rule).
  • Build rail networks early — the archaeologist's power comes from fast rail travel. If you neglect stations and railways, you'll spend all your action points crawling along roads.
  • Incomplete sets are weak — 2 monuments without a complete set = only 2 pts. Always aim for full sets (Arch + Temple + Tower) to get the 3-pt bonus.
  • One expansion only — you cannot combine Monuments with Lakes, Desert, or any other expansion in the same game.
