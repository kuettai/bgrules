🚣 Railroad Tiles: Canals

Expansion · 1–4 players · 30 min · Horrible Guild

📦 What's New

Adds Venice-inspired canals, bridges, and gondola meeples as a new network type alongside roads and rails.

🌊 Canal Tiles

New tile type featuring waterway segments. Build long, connected canals for points.

🌉 Bridges

Some canal tiles have open route gaps spanning the canal. A bridge is built when both ends of that route connect to other tiles.

🚣 Gondola Meeples

Placed on canals. Each gondola scores 1 point + 1 per bridge in the same canal.

🔚 Canal End Tokens

Used to close open canal ends. Connect a canal to the empty side of a tile, then place a Canal End token on it.

🔀 Rule Changes
  • Canal placement: Canal tiles connect edge-to-edge like regular tiles. Canals form a continuous waterway network.
  • Building bridges: When a route on a canal tile has an open gap over the water, the bridge is automatically constructed once both ends of that route are connected to adjacent tiles.
  • Closing canals: Connect an open canal end to the empty (non-canal) side of any tile, then place a Canal End token on it. Each unclosed canal end is −2 points at game end.
  • Gondola placement: Gondola meeples are placed onto canal segments during the game.
  • All other base-game rules remain unchanged — roads, rails, and standard scoring still apply.
⚠️ Bridges require both sides of the route to be connected — one side alone is not enough.
⚙️ Setup Changes
  1. Set up the base game as normal.
  2. Place the Canals tile bag beside the Core Box bag.
  3. Each round, fill the tile display using a pre-determined mix of core tiles and canal tiles. Each column still has the same number of tiles as indicated by the square icons — total tile count per round stays the same.
  4. Place Canal End tokens and gondola meeples in a shared supply.
💡 The total tiles available each game stays the same as base game — some core tiles are simply replaced by canal tiles, keeping game length consistent.
🏆 Scoring Changes
  • Canal length: Each canal scores 1 Prestige point per tile after the second. A 5-tile canal = 3 points. (A 1- or 2-tile canal = 0 points.)
  • Gondolas: Each gondola scores 1 point + 1 per bridge in the same canal.
  • Open canal ends: Each unclosed end = −2 points.
  • Base scoring unchanged: Roads, rails, and other base-game scoring still apply as normal.
💡 A gondola on a canal with 3 bridges scores 4 points (1 + 3). Maximise bridges before placing gondolas.
⚠️ Gotchas

❌ Bridges ≠ both sides connected

A bridge only exists when both ends of the route spanning the canal are connected to tiles. One side connected does nothing.

❌ Gondola scoring confusion

Gondolas score based on bridges in the same canal — not the number of other gondolas or canal length.

❌ Forgetting open ends

Each unclosed canal end is −2 points. Close them by connecting to an empty tile side and placing a Canal End token.

❌ Short canals score nothing

Canals of 1 or 2 tiles score 0 for length. You need at least 3 tiles before the canal itself earns points.

⚠️ Long canals with many open ends can be a net negative. Close ends before extending further.
