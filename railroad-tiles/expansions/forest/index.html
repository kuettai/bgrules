🌲 Railroad Tiles: Forest Expansion

Expansion · "Easy" Complexity · 1–4 Players · ~30 min · Designer: Hjalmar Hach · Horrible Guild

📦 What's New

The Forest Expansion adds two new elements to Railroad Tiles:

  • Forest tiles — new landscape tiles featuring forests that group together orthogonally, similar to how cities work in the base game.
  • Lookout Tower meeples — wooden tower pawns placed on special pinpoints found on some forest tiles. They score based on surrounding forests and proximity to other towers.

Also includes a set of expansion-specific objective tiles (e.g. Witch's House, Camping Ground).

💡 Rated "Easy" complexity — a great first expansion to try, or one to use with newer players. It adds variety without overhauling the rules.
🔀 Rule Changes

Forest Tiles

Forest tiles are placed into your landscape following normal placement rules. Orthogonally adjacent forest tiles form forest groups — keep groups separate from each other to maximize scoring (each qualifying group scores independently).

Lookout Towers

Some forest tiles have pinpoints where you can place a Lookout Tower meeple. Towers follow the same placement timing as other meeples — you place them when matching symbols appear on the active circular discs.

  • Lookout Towers can be placed using any Placement token as a wild card (like gondolas in the Canals Expansion), instead of requiring a specific disc symbol.
  • Towers score based on surrounding forest tiles in orthogonal directions (see Scoring Changes).
  • Towers also reward proximity — being exactly 2 spaces away from another Lookout Tower is the key distance for bonus scoring.
💡 The wild-card placement rule means you can place a Lookout Tower whenever any active disc matches — giving you more flexibility than standard meeples.
⚙️ Setup Changes
  1. Set up the base game as normal.
  2. Add the Forest tile bag — when refreshing the display each round, replace 1–2 base game tiles per column with forest tiles drawn from this bag (follow the pattern on the expansion flyer).
  3. Replace 3 circular discs from the base game stack with the 3 discs showing Lookout Tower symbols.
  4. Place the Lookout Tower meeples in the general supply.
  5. If using objectives: shuffle the Forest Expansion objective tiles and select 3 at random (each player gets a copy).
⚠️ Only one expansion can be used per game. Do not mix Forest tiles/discs with another expansion.
🏆 Scoring Changes

Forest Groups (End-Game)

At end of game, each group of at least 3 orthogonally adjacent forest tiles scores 3 VP.

  • Groups of 1–2 forest tiles score nothing.
  • Multiple separate groups each score independently — keeping forests apart is rewarded.

Lookout Towers (On Placement)

Each Lookout Tower scores 1 VP + 1 VP per orthogonal direction (up/down/left/right) that contains at least 1 forest tile.

  • Minimum: 1 VP (tower with no adjacent forests in any direction).
  • Maximum: 5 VP (tower with forest tiles in all 4 orthogonal directions).

Expansion Objectives (If Used)

Each completed objective is worth 5 VP. Examples:

ObjectiveCondition
🏚️ Witch's HouseMust NOT be in the same row or column as any Lookout Tower
⛺ Camping GroundMust have at least 4 forest tiles orthogonally adjacent to it
💡 Investing in forests and towers means less focus on cities, rectangles, and standard meeple networks. Balance your scoring across all categories.
⚠️ Gotchas / Common Mistakes
⚠️ Forest groups of 1–2 tiles score zero. You need at least 3 orthogonally adjacent forest tiles for a group to be worth anything.
⚠️ Keep forest groups separate. Unlike roads/rails where bigger networks are better, forests score per qualifying group. Merging two groups into one giant forest means fewer scoring groups.
⚠️ Lookout Towers use wild placement. You can place a tower using any active disc symbol — don't wait for a specific tower disc. This is easy to forget.
⚠️ Tower scoring checks orthogonal directions, not adjacency. A forest tile anywhere along the row/column from the tower counts — it doesn't have to be directly next to it.
⚠️ Replaced discs change the meeple economy. With 3 base discs swapped for tower discs, you'll have fewer rounds to place standard trains/cars/passengers. Plan accordingly.
⚠️ Objectives interact with expansion elements. Read each objective carefully — some penalize proximity to towers (Witch's House) while others require forests nearby (Camping Ground).
